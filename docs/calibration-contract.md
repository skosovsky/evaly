# Binary calibration contract

Calibration compares one declared grader revision with host supplied binary human labels. It does not measure human disagreement: each case has at most one label. Labels and records must have unique, nonempty case revisions, and every grade is validated, including records without labels. Different grader revisions are a conflict. Binary prediction means the existing `all` assertion rule; a scored numeric-only grade has no binary prediction and is an abstention.

The report is a new service wire format, `calibration` version 1. `Counts.Eligible` is the union of labeled and recorded cases, `Labeled` counts human labels, and `Reviewed` counts cases with both a label and a binary prediction. TP/TN/FP/FN use human pass as positive. `Unreviewed = Eligible - Reviewed`. Missing labels and missing records are counted explicitly. Errors count grader-error records; abstentions count non-applicable, insufficient-evidence, and numeric-only records. These diagnostic counts may overlap missing labels; they do not create predictions or zero scores.

Every rate stores its numerator, denominator, and nullable value. Coverage is Reviewed/Eligible; label coverage is Labeled/Eligible; accuracy is (TP+TN)/Reviewed; precision is TP/(TP+FP); recall is TP/(TP+FN); specificity is TN/(TN+FP); false-positive rate is FP/(FP+TN); false-negative rate is FN/(FN+TP). Zero denominator gives a null value, never a fabricated zero or one. Empty input is a valid unavailable report. Report validation checks all count identities and recomputes every rate. The report revision hashes its canonical representation with the revision field blank; tampering with aggregate data, rates, groups or grader provenance invalidates it.

Optional group labels belong to the host and attach to human labels. They are opaque names, unique per case. Each group reports the same counts and rates on its labeled cases, including missing records. Groups can overlap and must not be summed as disjoint populations. Reports retain no raw inputs, references, grade explanations, or sample content. Results are sorted by group name for deterministic persistence. Evaly does not infer representativeness, independence, causal effects, or acceptable error thresholds from these labels.

Breaking change: the former floating coverage and disagreement-only report are removed. Consumers use the explicit confusion counts and nullable rates. Numeric grades carry declared unit and scale revision, owned by the host; calibration never converts numeric scores to binary predictions.
