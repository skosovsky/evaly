# Measurement and comparison contract

Comparison v3 uses an explicit Objective port. Its frozen identity declares metric ID and revision, native unit, finite minimum/maximum scale, higher/lower direction, eligibility revision, missingness revision and aggregation revision (`repeat-mean-case-mean-v1`, the supported fixed arithmetic aggregation). The host owns domain meaning and independent case selection; case IDs cannot establish independence. The reference aggregation is the arithmetic mean of all planned repeats for a case, then the mean of matched cases. Repeats never increase independent N.

Eligibility is evaluated on the declared case identity before trial availability. Both sides must agree. Missing, failed or partially assessed final attempts are excluded with explicit reasons and never receive zero. A measurement is either present with a finite in-scale value, or missing with a reason. Numeric reference measurements select one declared grader/metric and verify unit, scale revision, range and direction. Assertion reference measurements apply the explicit all/any policy through the same port.

Compare(baseline, candidate, objective, policy) retains side coverage and the common declared eligible denominator. Gates require side coverage, minimum matched coverage and minimum matched case count. Incompatible manifests or measurement metadata produce invalid comparison; insufficient samples produce inconclusive. Quality, regression, delta and paired case bootstrap use exactly the same matched cases, in the objective native scale. For lower-is-better objectives, quality is an upper threshold and regression reverses the delta direction. Thresholds are product policy, not significance tests.

The report retains objective provenance, per-case exclusions and independent sample count. Empty and one-case intervals carry explicit unavailable/degenerate reasons. Bootstrap assumes representative independent cases; the host owns group, time and content splits. There is no cluster bootstrap, sequential testing or multiple-comparison correction.

Breaking changes: Compare requires an Objective; MeanPassRate is replaced by Mean; comparison wire version is 2; numeric metrics declare Unit and ScaleRevision. There is no alternate assertion-only Compare path.

Reference identities also retain assertion policy or selected grader/metric. Unknown side means and matched means/delta use explicit availability flags; the report renders them as unavailable. A constant multi-case bootstrap sample records a degenerate reason. Objective identities are checked after callbacks, and each measurement callback receives a fresh permitted trial snapshot.

Numerical limits: both endpoints and their scale span (maximum minus minimum) must be representable as finite float64. Values and reported statistics follow ordinary floating-point rounding. Online means preserve identical values, including subnormal minima, without overflowing a full sum. The paired bootstrap uses the same stable mean; opposite-sign differences whose subtraction overflows use wider standard-library arithmetic for that update. This does not promise arbitrary-precision statistics.
